# План: до «замены Spotify» — шесть задач

Выбрано владельцем 2026-11-02: офлайн (1), плейлисты (2), продолжение на другом
устройстве (5), слияние дублей (6), таймер сна / эквалайзер / ReplayGain (8),
Android Auto (10).

Правило работы: одна задача = один коммит, каждая считается сделанной только
после проверки на живом сервере и в клиенте (скриншот или curl), а не «код есть».

## T1. Плейлисты в клиенте — DONE

API уже есть (`/api/playlists`, треки, переупорядочивание), UI нет.

- вкладка «плейлисты» в библиотеке: список карточек, счётчик, «＋ новый»
- экран плейлиста: мозаика обложек, play, переименование, удаление, drag-порядок
- «добавить в плейлист» в меню трека (лист с существующими + создать)

**Приёмка:** создал плейлист, добавил два трека, переставил, переименовал,
перезапустил приложение — всё на месте; повторный запуск не дублирует треки.

## T2. Продолжить на другом устройстве — DONE

- сервер: `POST /api/playback` (трек, позиция), `GET /api/playback` — на юзера
- клиент: каждые 10 с во время игры отправляет курсор; при старте, если курсор
  не наш и свежий (< 7 дней), на главной появляется «продолжить «X» · 1:23»

**Приёмка:** два токена; первый «сыграл» 60 с трека, второй видит кнопку с
правильным названием и позицией и продолжает с неё.

## T3. Таймер сна, эквалайзер, ReplayGain — DONE

- таймер: 15/30/60 мин и «конец трека», обратный отсчёт в меню плеера
- эквалайзер: 10 полос через mpv `af` (`equalizer`), пресеты flat/bass/vocal/night
- ReplayGain: `ffmpeg ebur128` считает LUFS на сборке фич, клиент выравнивает
  громкость до −14 LUFS с потолком усиления

**Приёмка:** таймер реально ставит паузу; эквалайзер слышно и он переживает
перезапуск; трек, записанный на 10 дБ тише, играет на слух так же громко.

## T4. Android Auto — DONE (манифест; проверить в машине)

- `automotive_app_desc.xml`, meta-data в манифесте, опора на MediaBrowserService
  из audio_service; описание дерева (исполнители/альбомы/плейлисты)

**Приёмка:** APK собирается с манифестом, `aapt dump` видит запись; проверить в
машине сможет только владелец — это записывается честно.

## T5. Слияние дублей — DONE

- `GET /api/library/duplicates` — группы артистов/альбомов с нормализованным
  совпадением имён и перечнем треков
- `POST /api/library/merge` — переносит треки и удаляет проигравшего
- экран в настройках → библиотека

**Приёмка:** тест на временной БД: два артиста «Nirvana» и «Nirvana (US)»
сливаются, треки не теряются, альбомы переезжают, повторный поиск дублей пуст.

## T6. Офлайн — DONE

- скачивание в файл с докачкой по Range, очередь, лимит места, вытеснение
- «скачать» в меню трека, «скачать всё» на альбоме/плейлисте
- экран «скачано»: размер, очистка, статус
- плеер играет с диска, если файл есть; сервер не нужен

**Приёмка:** скачал альбом, остановил сервер, трек играет; места считается
честно; удаление файла возвращает на стрим.

## T7. Рекомендации: обученный дескриптор вместо самодельного — DONE

- `tools/embed_clap.py` считает CLAP-эмбеддинги (512-d) через ONNX офлайн, пишет в
  `embed(model='clap-v1')`; сервер ONNX не линкует.
- `features::active_model` выбирает обученную модель, как только она покрывает
  половину библиотеки; dsp-v1 остаётся фолбэком.
- `src/bin/eval.rs` — прокси-метрика recall@20 по «тот же артист / тот же альбом»
  на прослушанных треках, плюс контроль случайным ранжированием.

Замер (54 запроса, top-20): dsp-v1 artist 0.815 / album 0.685 / MRR 0.739;
clap-v1 0.833 / 0.722 / 0.782; случайно 0.778 / 0.370 / 0.306.

Оговорка: artist-метрика почти насыщена (18 артистов), поэтому +2% там мало о чём
говорят; album и MRR (+5%, +6%) честнее. Независимое подтверждение, что CLAP
понимает смысл: текстовые запросы («чиптюн» → Toby Fox, «пианино» → пианинные
треки, «ночное» → Treefingers / Quiet Water) — этого dsp-v1 не умеет вовсе.

## T8. Вкус из прототипов, а не из среднего — DONE

`src/taste.rs`: k-means (k ≤ 8) по позитиву, сессия (последние 10 треков с
затуханием 0.85), контекст по 6-часовому бакету за 30 дней, новизна как бандит с
одним рычагом (доля дослушанных среди впервые услышанных, с приором).
Скор: 0.45 сид + 0.30 лучший прототип + 0.15 контекст + 0.10 сессия, потом
штрафы; скип весит по глубине (уход на 5% трека — вердикт, на 90% — пожимание).

## T9. «Не это», пересборка подборок, настроение по словам — DONE

- `POST /api/recs/reject` пишет событие 5; отклонённые исключаются из волны.
- `POST /api/recs/daily/refresh` пересобирает подборки на сегодня.
- `GET /api/recs/mood?q=` — фразы из `tools/phrases.txt` с векторами CLAP,
  сопоставление по 4-буквенным стемам; в поиске появился блок «по звуку: «…»».
- В статистике появились доля и глубина скипов (59% и 3% на текущих данных).

# Десктоп-клиент на GPUI (с 2026-11-08)

Владелец: «перепишем на красивейший gpui», «прозрачность с десктопом»,
«максимальная красота». Референс — macOS-vibrancy: окно-стекло, за ним
размытый рабочий стол.

Телефон остаётся на Flutter: в опубликованном `gpui` есть только linux/mac/
windows, Android-бэкенда нет.

## D1. Каркас, библиотека, комната — DONE

Crate `desktop/`, Wayland+Vulkan, шрифт Geist, палитра из обложки, сетка
альбомов, экран альбома, плеер-бар. Покрытия: webp 512 для сетки, JPEG XL 768
для «комнаты».

**Приёмка:** `cargo build`, окно открывается, 49 альбомов с обложками, альбом
открывается и играет.

## D2. Звук — DONE

`audio.rs`: две deck-колоды на одном микшере, equal-power кроссфейд по Camelot,
prefetch, ReplayGain из LUFS, события в taste. `track_source.rs`: сервер отдаёт
Opus по политике → декодер `opus-pure` (чистый Rust), pre-skip, seek.

**Приёмка:** позиция растёт, seek на 60 с даёт ровно 60 с (был баг ×2),
события в БД по одной строке на проигрывание (было ×3).

## D3. Аудит и починка 12 дефектов — DONE

См. коммит `desktop: the room adapts…`: двойной seek, тройные события,
незаглушённая вторая колода, пауза мимо входящей колоды, мёртвая кнопка play
после конца очереди, битый кусок после seek в Opus, отсутствие PLAY_END,
кэш обложек не перекрашивал комнату, порог перерисовки 120 мс при тике 100 мс,
MPRIS 10 раз/с, mute без перерисовки, 270 МБ текстур.

## D4. Стекло — DONE

`WindowBackgroundAppearance::Blurred`, server-side decorations (иначе niri
рисует плашку фокуса за CSD-окном), hue 0..1 вместо градусов, палитра
светлая/тёмная по перцептивной яркости, зерно/виньетка/радиальное свечение
текстурами (шейдеров в gpui нет).

**Приёмка:** альфа сходится с арифметикой до 3 RGB, в niri blur σ≈9.5 px;
скриншоты снимаются в приватной headless-сессии sway, рабочий стол владельца
не трогается.

## D5. Осталось

- настройки (сервер, качество, кроссфейд, эквалайзер, таймер сна)
- плейлисты и «добавить в плейлист»
- каст (Chromecast/DLNA) с десктопа
- упаковка: CI-джоб на Linux-бинарник, AppImage/тарбол
- волна: дозагрузка при проигрывании из неё (сейчас очередь фиксируется)
