# План: до «замены Spotify» — шесть задач

Выбрано владельцем 2026-11-02: офлайн (1), плейлисты (2), продолжение на другом
устройстве (5), слияние дублей (6), таймер сна / эквалайзер / ReplayGain (8),
Android Auto (10).

Правило работы: одна задача = один коммит, каждая считается сделанной только
после проверки на живом сервере и в клиенте (скриншот или curl), а не «код есть».

## T1. Плейлисты в клиенте — DONE

API уже есть (`/api/playlists`, треки, переупорядочивание), UI нет.

- вкладка «плейлисты» в библиотеке: список карточек, счётчик, «＋ новый»
- экран плейлиста: мозаика обложек, play, переименование, удаление, drag-порядок
- «добавить в плейлист» в меню трека (лист с существующими + создать)

**Приёмка:** создал плейлист, добавил два трека, переставил, переименовал,
перезапустил приложение — всё на месте; повторный запуск не дублирует треки.

## T2. Продолжить на другом устройстве — DONE

- сервер: `POST /api/playback` (трек, позиция), `GET /api/playback` — на юзера
- клиент: каждые 10 с во время игры отправляет курсор; при старте, если курсор
  не наш и свежий (< 7 дней), на главной появляется «продолжить «X» · 1:23»

**Приёмка:** два токена; первый «сыграл» 60 с трека, второй видит кнопку с
правильным названием и позицией и продолжает с неё.

## T3. Таймер сна, эквалайзер, ReplayGain — DONE

- таймер: 15/30/60 мин и «конец трека», обратный отсчёт в меню плеера
- эквалайзер: 10 полос через mpv `af` (`equalizer`), пресеты flat/bass/vocal/night
- ReplayGain: `ffmpeg ebur128` считает LUFS на сборке фич, клиент выравнивает
  громкость до −14 LUFS с потолком усиления

**Приёмка:** таймер реально ставит паузу; эквалайзер слышно и он переживает
перезапуск; трек, записанный на 10 дБ тише, играет на слух так же громко.

## T4. Android Auto — DONE (манифест; проверить в машине)

- `automotive_app_desc.xml`, meta-data в манифесте, опора на MediaBrowserService
  из audio_service; описание дерева (исполнители/альбомы/плейлисты)

**Приёмка:** APK собирается с манифестом, `aapt dump` видит запись; проверить в
машине сможет только владелец — это записывается честно.

## T5. Слияние дублей — DONE

- `GET /api/library/duplicates` — группы артистов/альбомов с нормализованным
  совпадением имён и перечнем треков
- `POST /api/library/merge` — переносит треки и удаляет проигравшего
- экран в настройках → библиотека

**Приёмка:** тест на временной БД: два артиста «Nirvana» и «Nirvana (US)»
сливаются, треки не теряются, альбомы переезжают, повторный поиск дублей пуст.

## T6. Офлайн — DONE

- скачивание в файл с докачкой по Range, очередь, лимит места, вытеснение
- «скачать» в меню трека, «скачать всё» на альбоме/плейлисте
- экран «скачано»: размер, очистка, статус
- плеер играет с диска, если файл есть; сервер не нужен

**Приёмка:** скачал альбом, остановил сервер, трек играет; места считается
честно; удаление файла возвращает на стрим.
