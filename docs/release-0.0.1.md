Первый рабочий выпуск: библиотека на сервере, клиент на Flutter, рекомендации по звуку.

## Что работает

- FLAC-мастера, теги, обложки, формат виден в каждой строке
- артисты и альбомы по буквам, страницы артиста и альбома, лайки
- плеер: волна в обе стороны, перемотка тапом, кроссфейд на двух деках, gapless
- акцент из обложки на весь интерфейс
- дневные подборки по настроению и похожести, вкус из прослушиваний и скипов
- двенадцать слов вместо пароля: один слушатель на всех устройствах
- серверные страницы /a/<id> и /al/<id> для телефона в Tailscale

## Установка

**Android** — скачать APK, открыть, разрешить установку. Адрес сервера зашит
в сборку и меняется в «настройках».

**Linux** — распаковать архив и запустить `bulba-music.sh`.

## Ограничения

- офлайн-скачивания на телефон пока нет: играет стримом
- кроссфейд без beatmatch: темп не выравнивается
- сборка ждёт сервер по `http://100.108.226.86:8422`; свой адрес — в настройках
