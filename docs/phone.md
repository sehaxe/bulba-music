# Телефон

## Сеть

Сервер живёт на десктопе и слушает `0.0.0.0:8422`. Снаружи он виден только
через Tailscale:

- адрес: **http://100.108.226.86:8422**
- имя: `http://supermicro-cachyos.tail3a20da.ts.net:8422`

Оба работают, пока на телефоне поднят Tailscale и он в том же tailnet.
Проверка с телефона: открыть `http://100.108.226.86:8422/api/health` — должен
прийти JSON с `"ok":true`.

## Сервер как сервис

```
systemctl --user status bulba-music
systemctl --user restart bulba-music
journalctl --user -u bulba-music -f
```

`Linger=yes` уже включён, поэтому сервер поднимается после перезагрузки и без
входа в графическую сессию.

## Приложение

APK: `app/build/app/outputs/flutter-apk/app-release.apk`.
Поставить: скинуть на телефон и открыть, разрешить установку из этого
источника. Подпись отладочная, обновления ставятся поверх.

Адрес сервера уже зашит в сборку. Если tailnet поменяется — «настройки →
о системе → сервер», вписать новый и сохранить.

## Аккаунты

На компьютере: «настройки → синхронизация → создать фразу», двенадцать слов
показываются один раз. На телефоне: «ввести фразу», те же слова через пробел.
После этого история, лайки и подборки — общие.
